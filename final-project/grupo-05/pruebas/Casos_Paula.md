# Casos reproducibles del bloque de Paula

El [guion SQL](02_bloque_paula.sql) contiene las preparaciones, acciones y consultas completas. Cada enlace de fila localiza la acción/aserción correspondiente. El resultado esperado ya estaba expresado en la condición SQL o en el SQLSTATE/restricción antes de ejecutar. La tabla siguiente se obtuvo de las salidas efectivas de `GET STACKED DIAGNOSTICS` y de las consultas de estado del guion, cotejando que **los 120 identificadores previstos tengan observación**: 105 rechazos correctos y 15 aserciones de datos.

La [transcripción íntegra](../evidencias/Ejecucion_Paula_Secuencial.md) conserva valores completos, consultas, confirmaciones y reversiones; los JSON de esta tabla abrevian columnas descriptivas largas. No se sustituyen observados por esperados. Cada rechazo se ejecuta en subtransacción y no deja efectos; si SQLSTATE o restricción difieren, el guion aborta. La evidencia de conjuntos R/H se consulta antes de ROLLBACK, y P15 vuelve a comprobar el estado persistido después. Cada ejecución requiere una base nueva; no hay limpieza destructiva.
